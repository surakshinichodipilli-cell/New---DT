# NetShield AI

## AI-Based Cybersecurity and Network Protection System

### Project Overview
NetShield AI is a cybersecurity project designed to help users identify potential online security threats and network risks.

### Main Features
- Phishing URL Risk Detection
- Suspicious URL Analysis
- Unknown Device Monitoring
- Network Security Alerts
- Risk Score Assessment
- User-Friendly Dashboard

### Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning

### Installation and Execution

1. Download or clone the project.
2. Install the required Python packages:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000/

### Project Purpose
The main objective of NetShield AI is to improve cybersecurity awareness and help users understand potential online and network security risks.
